# Editable art sources

Store reviewed source models, rigs, textures and audio here. Export Unity runtime
assets under Assets/Ninefold; retain editable sources. Large binary types are
configured for Git LFS. Verify LFS fetch on local and cloud checkouts before use.

Model in meters and preserve locked body plans, equipment and relative scale.
Record source/master version, export settings and asset provenance with each asset.
No production artwork is included in the initial scaffold.
