# World Five — Bonded Traditions Combat Pass 01

**Status:** playable-unit ability study, isolated from shipped Unity campaign and existing save revisions.

This pass establishes four different Main ability effects for the four standard bonded traditions. All four use existing validated core ability rules; no random misses or unimplemented movement/status effects are claimed.

| Tradition | Main ability prototype | Battle niche |
| --- | --- | --- |
| Great Strider / Ilyth | Damage, medium range | Route confrontation and controlled pressure |
| Living Veil / Olyra | Ally/self healing | Protection and recovery |
| Riftwalker / Vaskel | Short-range high-impact damage | Close positioning |
| Burdenbeast / Tervan | Damage, medium range | Defensive pressure through deployable hardware |

The numeric values are engineering placeholders, **not** final lore-locked abilities. The final versions should have world-specific effects and visuals: traversal, protection, realignment and infrastructure deployment. Those require a follow-on core-mechanics pass rather than pretending a simple damage/heal profile provides them.

**Boundary:** this is an opt-in `WorldFivePlayableAbilityStudy` catalog built on the Act One candidate. It does not replace current Unity scene selection or active profiles. The existing Ashbound combat kits, unit model files and animation files remain unchanged.
