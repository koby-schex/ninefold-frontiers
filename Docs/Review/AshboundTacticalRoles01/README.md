# Ashbound tactical roles — encounter study v3
Campaign-only, nonplayable NPCs. In missions 12–14, Foragers and Strikers retain **aggressive pursuit**. Castigators, Seers, Wreckers and Witnesses now use the existing **defensive** combat planning behavior with a world-map guard bound. This causes defensive roles to prefer legal supportive actions and avoid pointless pursuit, while close-range aggressors still close on targets they can perceive. Their preferred engagement distances remain distinct.

**Limits:** This reuses preexisting combat AI styles; it does not yet implement true role-specific sabotage, coordinated ally buffs, retreat conditions or environmental hazard interaction. Mission 11 and the ten tutorial missions are unchanged; this new opt-in content catalog has a separate revision and profile ID, so existing v2 encounter-study saves must not be opened against it. Unity's entry currently references v2 folder/name and will need an aligned version bump before selecting the new study. No model or animation assets changed.
