# World Five Combat Mechanics 01
Isolated, opt-in prototype. Adds **real Core status effects** attached to existing playable-unit and Ashbound abilities. No save migration or live Unity asset modifications.

**Playable:** Living Veil/Olyra Main healing also grants shelter (+25% armor for two owner activations). Riftwalker/Vaskel and Burdenbeast/Tervan Main damage also expose a target (-18% armor). Great Strider remains on the existing attack prototype; its traversal-specific mechanic is not yet implemented.

**Ashbound:** Seam Castigator Main damage disrupts target power (-15%). Anchor Wrecker Main exposes armor. Initiated Parted Striker and Afterecho Seer suffer the Afterecho (-18% armor, -10% power) on their own activation start, using the existing deterministic passive/status engine.

**Limitations:** These are status prototypes, not finished animations, fracture displacement, deployables or finalized lore abilities. Player-facing animations, telegraphs, unique model assets, enemy AI tactical selection and Unity menu hookup remain separate tasks. Existing ten-mission V4 and Act One profiles untouched. No Apex or collectible Ashbound templates added.
