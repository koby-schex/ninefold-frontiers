# World Five tutorial mid-campaign journey

Registered integrated regression continuing **the same saved player profile** from the already-proven victories in Missions 1–3. Instead of merely spawning Mission 4, it actually advances three further authored objectives:

- Mission 4: move playable squad members into the secure zone, hold two consecutive turns, earn victory and persist rewards. Mid-battle save/reload proves the zone control encounter resumes.
- Mission 5: survive a two-round protect-the-traveler encounter and resolve actual mission success.
- Mission 6: survive three completed rounds and collect a victory.
- After each battle: claim rewards exactly once, return to selection, reopen the saved profile, verify mission unlock and exactly one additional receipt.
- Verify Mission 4 cannot be deployed before completing Mission 3.

Enemy perception is intentionally empty to isolate core mission objective/progression behavior from AI difficulty. This is **not** full tutorial certification: Missions 7–10, wildlife combat, Mission 9's second rescue, actual enemy pressure, Unity graphics and on-device controls still need integrated journey coverage. Existing save formats, campaign data and unit art remain unchanged.
