# Tutorial wildlife behavior v2

Missions 7 and 8 now have different encounter styles instead of sharing the same pursuit brain. Two Seamstalkers in Mission 7 **aggressively pursue** perceived opponents; the lone Sillrunner in Mission 8 **holds its territory** with the existing defensive AI, fitting a startled native creature protecting space rather than a dedicated hunter. Existing AI strictly uses legal perceived targets and respects combat rules.

This is an opt-in content revision using a new saved-profile directory. World Five stays the only tutorial campaign, the number of native creature encounters remains limited, and no Ashbound appear before Mission 11.

**Not yet included:** distinctive creature models, skeletal animations, ecological escape behavior, or standalone wildlife story beats. Existing Unity game behavior should be playtested on device.
