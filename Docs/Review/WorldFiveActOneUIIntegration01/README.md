# World Five Act One UI Integration 01
Adds an **opt-in Act One study** entry button when viewing the World Five tutorial prototype on Home. This opens a separate `WorldFiveActOneStudy-v1` profile using the `WorldFiveCombatMechanicsV1` content catalog. The prototype contains tutorial 001–010 and the first Ashbound encounter, now player-labeled **Mission 11**. It keeps V4 saves untouched, never auto-migrates or silently replaces active battles, and refuses to switch until the current profile is in the Selection phase.

**Known limitations:** The Act One study is a fresh separate profile, not a migration of old completion. Users need to play tutorial missions again there. Enemy status mechanics are active in this catalog, but existing AI ability selection remains limited. Dialogue, story briefings, final visuals, dedicated animation models and full on-device end-to-end victory testing remain outstanding. This is a controlled integration step, not a completed production campaign.
