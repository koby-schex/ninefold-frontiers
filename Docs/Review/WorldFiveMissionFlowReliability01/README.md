# World Five Mission Flow Reliability 01

Adds regression tests against the actual ten-mission V4 prototype catalog and its real MissionPresentation interface. These verify initial campaign locks, persistence of locked-stage restrictions across profile reopening, and active battle recovery after restarting the menu.

This does not simulate all ten mission victories, certify complete campaign playthroughs or alter release balance. Existing profile IDs, save formats, layouts, Ninefold UI presentation and separate 3D model work are unchanged.

Run repository tests on Windows and Linux and playtest Unity campaign navigation on device before release.
