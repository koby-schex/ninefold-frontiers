# Campaign Progression & Player Experience Reliability 01

Three additive core integration tests validate that the next playable campaign mission remains available after completing a predecessor and reopening a profile, locked missions cannot be prepared before prerequisites, and reward claims remain idempotent across reloads. This extends existing menu and campaign test coverage.

These fixtures use the tested abstract campaign to validate public menu contracts; they do not assert that all ten World Five prototype missions can yet be manually completed. No runtime progression tuning, saved-game format, screen design or 3D assets change. Maintain Ninefold-wide coherent navigation, branding and high-quality touch presentation in all subsequent visual passes.
