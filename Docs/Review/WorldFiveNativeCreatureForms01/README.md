# World Five native wildlife — procedural creature form pass 01

Changes the two tutorial wildlife species from single primitive tokens into assembled, recognizable low-profile quadrupeds in Unity's abstract battlefield. Sillrunners have a broad balance fan; Seamstalkers have a tapered tail and raised shoulder structure. Both use separate body, head, four limbs and sensory ridges. Creature parts are children of the existing token root and are cleaned up with the token. They retain the same in-game scale policy, target picking, navigation, health rules and inherited attack/impact motion.

This is an **early procedural anatomy blockout**, not approved canon creature anatomy, textured production meshes, organic skeletal animation, real gait, nor an asset to print. No playable unit models or animation rig files are modified. The next pass should target higher-detail sculpt-like geometry and actual limb/torso animation after Unity visual review.
