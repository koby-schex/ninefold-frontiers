# Unit Combat Identity 03 — Frontline & Striker

Adds a separate noncanonical engineering balance catalog (`UnitCombatRolesV4`) based on the V3 unique-stat roster. Fixture A-1 is a durable frontline unit (2,450 HP, 420 armor, self/ally healing main); fixture A-3 is a lower-defense damage specialist (1,565 HP, 125 armor, offensive main). Fixture A-2 remains the support healer. Normal and signature attack damage remain unique for every unit template, and tests enforce that invariant.

This is not yet wired into the live Unity V4 campaign. It retains the existing ability-slot/action semantics and the same authored campaign maps. Old V2/V3 profiles and production World Five saves are untouched. Values and identities are provisional, not canon-approved or final balance. Future work: real defensive abilities/statuses, tactical synergies, approved canonical assignments, and Unity playtesting.
