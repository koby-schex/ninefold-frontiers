# First Encounter Models — Seamstalker, Sillrunner, Rift Forager

**Scope:** Major coordinated batch for the first three *distinct named hostile templates* in the current tutorial-wildlife/Act One playable catalog: Mission 7 Seamstalker, Mission 8 Sillrunner and Mission 11 Rift Forager. Mission 11 also introduces Parted Striker; its visual remains unchanged. Earlier abstract fixture NPCs are not promoted to fictional species. This decision follows the current mission ordering rather than treating the first three names in the Ashbound roster as the first three encountered.

**Status:** actual live Unity fallback assets, with substantive new body geometry and rigging. NOT yet native Unity-compiled/visually approved, phone-profiled, or locked canon. Existing approved prefabs retain precedence. The proposed wildlife design record `Docs/Design/WorldFiveNativeEcology01/PROPOSED.md` describes six-limb anatomy, in contrast to the old provisional four-limb mesh. The six-limb proposals are implemented as provisional candidate art (not lore-locked), retaining the existing runtime species palettes and no new gameplay ability. The approved Ashbound addendum controls nonhuman Avarin anatomy, living crescent, external engineered hardware and absence of bonded creatures. Master Lore & World-Building Archive v26.0 and approved art remain authoritative.

## What changes in the actual game

| Model | Body anatomy | Movement and surface work |
| --- | --- | --- |
| Seamstalker | Long distinct predatory trunk, tapered tail, split sensory crown, paired fore anchor-claws, six independently articulated legs, integrated cheek/eye, belly and dorsal contours | Skinned 15-joint continuous body, alternating tripod gait, flexing lower legs, aggressive head strike, tail counterbalance, distinct skin/accent/eye materials |
| Sillrunner | Broader rounded yet continuous low profile, segmented lateral sensory folds, broad rear balance fan, six low-set legs, real dorsal folds and cheek/eye surface | Separate generated topology, quick alternating tripod gait, head/fin/tail articulation, restrained reaction, separate material treatment; not a color-swapped Seamstalker |
| Rift Forager | Connected rest body replaces separate torso, neck, face, arms, legs and heel lofts; tapered Avarin temple-face; paired living crescent and original external route tools remain exactly in the existing runtime art path | Weighted body uses existing actual in-battle core/head/arms/legs pivots and action motion; fitted two-layer asymmetric waist cloth adapted from preceding ArtReview construction, closed borders and normal geometry, differentiated clothing/hide response |

The second integrated visual pass removes the jagged centroid-painted wildlife eye patches and replaces them with fitted closed corneal oval geometry and thin material-assigned rims. It makes the Sillrunner more distinctly low-set and broad-nosed, with shorter legs and a restrained dorsal palette; the Seamstalker receives a narrower muzzle, sweeping split crown and hooked foreclaws. The Forager receives narrower pelvic and upper-temple contours. This refinement stays in the same consolidated PR.

The old Forager ArtReview 19-bone candidate remains separately preserved. The new live Forager skin uses the existing six anatomically aligned runtime transforms to preserve compatibility with the attached mantle, field equipment and shipped motion system; it is not a direct transplant of the distinct rest poses. Source gear pivots, actor root, authoritative battle coordinates, hit certainty, targeting, mission history, approved prefabs and all gameplay data remain unchanged. The wildlife meshes use real indexed shared-edge tetrahedral extraction, gradient normals, continuous surface regions and UVs, with no primitive replacement overlays. Stored source data is generated lazily; matching runtime actors reuse the same Unity mesh asset and use distinct skeletons. Battle-owned resources still dispose exactly once across transitions.

## Combined review and acceptance

The new **First encounter model review** GitHub Actions workflow exports the actual runtime C# rest meshes for all three named models and the Forager's real two-panel cloth. It renders one detail sheet (four angles per unit), one tactical sheet (three angles per unit), publishes real OBJ files and a JSON metrics file. Forager images are transparently labeled as **body + cloth**, excluding source gear and mantle (those are separate live runtime nodes). Static review uses current color swatches and normals, not native Unity, actual PBR, animation or FPS.

Core tests execute actual generated geometry checks for the three meshes and tailored clothing: finite normals, all material areas, edge manifoldness, one connected body, joint coverage, six wildlife anatomical joints per side pair, distinct silhouettes, source eye clearance and real cloth fit. Encounter order is checked against the current playable catalog. Existing Windows/Ubuntu gameplay and structural validation are retained.

Native acceptance in Unity 6000.3.21f1: play Mission 7 and 8 and Mission 11 with no override prefab selected for these templates. Review all three at once, compared with the source art, including silhouette, six-limb wildlife proposal, Forager face/mantle/cloth, foot placement, idle, movement, attack, hit/defeat reaction, portrait readability and actual mobile frame time. Keep gameplay/AI/canon approval unit IDs untouched. The static source artifacts cannot certify native rendering, cloth/limb deformation, or device performance. No new canonical creature biology or gameplay approval is implied by merging the implementation.
