# World Five opening-campaign quality gate
This pass corrects player-facing mission labels to **Mission 1** through **Mission 14**, including the ten starter tutorial missions; internal story beat names remain internal. The V3 encounter-variety catalog now opens a matching separate V3 save directory rather than the obsolete V2 directory, protecting earlier experimental progress.

Automated content gates check fourteen missions ordered with chained prerequisites, wildlife exclusively in tutorial Missions 7 and 8, no Ashbound until Mission 11, first Ashbound encounter in Mission 11, and that starter units are player-rostered rather than hostile templates.

**Scope:** these are progression/content integrity tests and UI fixes, **not** an end-to-end victory playthrough of all fourteen missions. Full save/resume exercise for Mission 11, battle balancing, visual tutorial guidance and unlocking subsequent worlds require further gameplay work. Only World Five should ultimately be unlocked for new players; global multi-world selection is not yet implemented by this change.
